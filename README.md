# ForestSim
ForestSim is an interactive 3D forest environment developed in Java as part of my fifth-semester Computer Science studies at Roskilde University.

The project explores computer graphics in Java, particularly the integration of 3D models created in Blender into an application built using JavaFX and FXGL.

## Features
- Interactive 3D forest environment.
- Custom OBJ model loader for importing 3D models.
- Integration of Blender-created models into a Java application.
- Camera controls and user interaction.
- A forest scene containing trees, rocks, mountains, grass, and other environmental objects.

## Technologies
- **Java** — Core application development.
- **JavaFX** — Java graphics framework.
- **FXGL** — Game development framework.
- **Blender** — 3D modelling.
- **Maven** — Dependency management and project configuration.

## Technical Challenges
One of the main challenges was importing and displaying 3D models within the FXGL environment.

To address this, I implemented a custom OBJ model loader, allowing the application to load and render 3D assets.

This project provided practical experience with 3D graphics, model representation, scene construction, and working with graphics frameworks in Java.

## Project Background
Developed during the fifth semester of my BSc in Computer Science at Roskilde University (2025).

The project was an opportunity to explore 3D graphics programming and investigate the possibilities and limitations of Java-based graphics technologies.

## A Small Disclaimer 😅
FXGL was a requirement imposed by my project supervisor, rather than my personal framework of choice.
While working with it was certainly an *educational experience* (in more ways than one), if I were to revisit this project today, I'd probably approach the technical implementation quite differently.

But hey, figuring out how to make things work within constraints is part of software development, right?
